# Surface: Web App (apps/web)

## Direction Contract

### THESIS
Siam's Aqua is an 8-sector pharmaceutical distribution platform. The category default is dark glassmorphism with gradient blobs — we refuse that. Instead: a clean, light, modern e-commerce grid that feels as professional as Shopify or Amazon, with pharmaceutical-specific content that makes it feel authored for this product.

### OWN-WORLD
- **Palette:** White (#FFFFFF) ground, light gray (#F8F9FA) for subtle separation, #0F5B78 (deep clinical slate-cobalt) for primary actions and authority, neutral grays for text hierarchy. No gradients, no glass, no decorative color.
- **Typography:** Clean sans-serif (Inter or similar) for body, slightly more characterful face for headings that still feels institutional. Clear scale: 14px body, 16px/18px/24px/32px headings.
- **Components:** Clean product cards with subtle borders, elevated on hover. Standard form inputs with clear labels. Data tables with zebra striping. Toast notifications instead of alerts. Clean navigation with active states.

### STORY
A pharmacy owner opens the app, sees their sector portal, searches for medicine, adds to cart, configures fulfillment, and confirms. Every step is clear, fast, and professional. The platform feels trustworthy — like ordering from a real pharmaceutical distributor, not a side project.

### FIRST VIEWPORT
Clean header with Siam's Aqua wordmark + sector navigation. Below: 2-column layout — left sidebar with sector cards (8 sectors as clean, labeled cards with icons), right side with main content (product grid or dashboard). Cart indicator in navbar. Search bar prominent. No gradient blobs, no glassmorphism, no decorative blur.

### FORM
Modern e-commerce grid — product-focused layouts, clean filters, scannable cards. Shopify/Amazon-style. Familiar patterns executed at high fidelity with pharmaceutical-specific content.

### FINISH
Unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
